# Отчёт о лабораторной работе

* **Название работы:** Моделирование группового поведения биологических и технических агентов с использованием алгоритма Boids Крейга Рейнольдса
* **Дисциплина / Модуль:** Многоагентные системы и имитационное моделирование

## 2. Цель работы

Исследовать принципы работы алгоритма **Boids** (Крейг Рейнольдс, 1986) для имитации стайного поведения, разработать интерактивную программнуюы, а также оценить влияние изменения радиуса взаимодействия и весовых коэффициентов поведенческих правил на динамику и скоординированность многоагентной системы.

---

## 3. Описание модели

* **Среда:** Двумерное замкнутое пространство с непрерывными координатами $(x, y)$, где агенты при выходе за границы экрана плавно появляются с противоположной стороны.
* **Агенты:** Автономные объекты («бойды»), обладающие текущей позицией, вектором скорости, ограничениями по максимальной скорости (`maxSpeed`) и маневренности (`maxForce`), а также фиксированным радиусом восприятия (`perceptionRadius`).
* **Правила поведения:**
1. *Separation (Разделение):* Локальное отталкивание от соседей для предотвращения столкновений.
2. *Alignment (Выравнивание):* Стремление согласовать направление движения со средней скоростью соседних агентов.
3. *Cohesion (Сплочение):* Движение к центру масс видимой группы соседей.


* **Принятые допущения:** Масса каждого агента принимается равной единице ($m = 1$), взаимодействие является локальным (агенты реагируют только на соседей в пределах радиуса обзора), внешние факторы среды (ветер, препятствия) в базовой модели не учитываются.

---

## 4. Описание алгоритма

Логика работы алгоритма на каждом шаге симуляции для каждого агента состоит из следующих этапов:

1. **Поиск соседей:** Итерация по всем агентам стаи и вычисление расстояния $d$ до текущего бойда. Если $0 < d < \text{perceptionRadius}$, агент учитывается в расчете.
2. **Расчет управляющих векторов:**
* *Разделение:* Суммирование векторов смещения обратно пропорционально квадрату расстояния ($\Delta \mathbf{pos} / d^2$), что создает сильное отталкивание на критически близких дистанциях.
* *Выравнивание:* Накопление векторов скоростей соседей с последующим усреднением.
* *Сплочение:* Накопление позиций соседей для вычисления центра масс с последующим вектором тяготения к нему.


3. **Применение сил руления (Steering Force):**
* Расчет желаемой скорости и применение формулы Рейнольдса: $\mathbf{F}_{\text{steer}} = \mathbf{V}_{\text{desired}} - \mathbf{V}_{\text{current}}$.
* Ограничение результирующей силы по параметру $\max(\text{maxForce})$ для имитации инерции.


4. **Обновление состояния:** Обновление скорости агента с учетом весов правил ($w_{\text{sep}}, w_{\text{align}}, w_{\text{coh}}$), ограничение модуля скорости по $\max(\text{maxSpeed})$ и обновление координат позиции.

## 5. Реализация

Программа реализована на языке **Java** с использованием стандартной библиотеки **Java Swing** для графического рендеринга и кастомного парсера конфигураций для чтения `.env` файла.

### Основные компоненты системы:

* **`Config.java`** — статический модуль конфигурации, считывающий параметры симуляции (`MAX_SPEED`, `MAX_FORCE`, `PERCEPTION_RADIUS`, веса правил и др.) из файла `.env` при старте приложения.
* **`Boid`** — класс, инкапсулирующий физику агента, реализацию трех правил Рейнольдса, ограничение ускорения и обработку тороидальных границ экрана.
* **`BoidPanel`** — панель визуализации (`JPanel`), управляющая игровым циклом (`Timer`, ~60 FPS) и отвечающая за отрисовку агентов в виде направленных векторов с помощью `Graphics2D` и сглаживания (`RenderingHints.KEY_ANTIALIASING`).
* **`BoidsSimulation`** — главный класс приложения, инициализирующий оконную форму `JFrame`.

## 6. Результаты визуализации

* В ходе работы приложения при стандартных параметрах наблюдается формирование единой органичной стаи, движущейся волнообразно («эффект мурмурации»).
* Агенты успешно поддерживают дистанцию, не допуская физического слияния в одну точку благодаря нелинейному закону разделения ($1/d^2$).
* При выходе за границы экрана агенты бесшовно переносятся на противоположную сторону, сохраняя вектор движения.

## 8. Выводы

1. В ходе лабораторной работы был успешно изучен и реализован классический алгоритм группового поведения Boids Крейга Рейнольдса на языке Java.
2. Использование модульной архитектуры с вынесением управляющих параметров в `.env` файл позволило оперативно тестировать различные гипотезы без перекомпиляции исходного кода.
3. Экспериментально доказано, что:
* **Радиус взаимодействия** определяет масштаб видимости: слишком малый радиус приводит к дезинтеграции стаи, а слишком большой — к потере локальной гибкости движения.
* **Весовые коэффициенты** задают итоговый «характер» системы: доминирование правила разделения предотвращает коллапсы и столкновения, в то время как выравнивание и сплочение отвечают за гармоничное векторное движение всей группы.
